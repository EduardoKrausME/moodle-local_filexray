Installation and first steps

Install File X-Ray as a Moodle local plugin, check permissions and keep cron active for long-running inventories.

Requirements

The plugin targets Moodle 4.5 or later and requires administrative access for installation. Use a PHP version and database platform supported by your Moodle version. Moodle cron must be running to process ad-hoc inventory tasks.

Installation

Place the plugin in local/filexray, perform the standard Moodle plugin upgrade and open Site administration → Reports → File X-Ray. Access is governed by system-context Moodle capabilities.

CLI setup

php admin/cli/upgrade.php --non-interactive
php admin/cli/purge_caches.php
php admin/cli/cron.php

The last command runs one cron pass. A production installation should keep its existing recurring cron schedule active.

First report

Select Generate report to save a snapshot of the site's courses and enqueue the first task. The progress page shows per-course state and opens the comparison after processing. You can also enqueue a report using php local/filexray/cli/create_report.php.

Retention and deletion

The configuration provides a maximum report count. When that limit is reached, the oldest report is removed before creating a new one. Deleting a report deletes its own inventory records, not Moodle's original files.

File X-Ray does not use an external service, create a complete backup or produce an MBZ. Plan CPU and database usage for large installations.
