Reading comparison results

Compare per-course inventory totals with the file records currently stored in Moodle's logical file table.

Per-course results

Each course total comes from the saved inventory and contains reference counts and their summed logical byte sizes. Results remain available after the browser closes.

Compared datasets

Set A is the list of file IDs selected during course backups. Set B contains records in mdl_files. Records present in B but not in A are labelled as outside that report's inventory, not as confirmed orphaned files.

Changes over time

The report processes courses at different times, while Moodle's file table may change after the inventory. It is not a globally frozen transaction and the comparison depends on when files were updated.

Logical versus physical bytes

Summing filesize counts logical record sizes. Different records may share the same contenthash, which means logical totals cannot be treated as distinct on-disk usage or safely reclaimable bytes.

Course failures

A report with failed courses produces a provisional comparison. Retry failed courses before relying on the figures for administrative decisions.

Records outside backup

A paginated list shows file records not selected by the inventory. Their filename, component, file area, context and byte size can help with manual investigation.

Never delete mdl_files records or moodledata/filedir content just because they do not appear in course backup inventories.
