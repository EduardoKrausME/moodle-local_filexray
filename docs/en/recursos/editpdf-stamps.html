PDF annotation stamps

Stamp images used by teachers when annotating PDF submissions. They may be globally configured and reused in assignment feedback.

What these files are

assignfeedback_editpdf / stamps — Stamp images used by teachers when annotating PDF submissions. They may be globally configured and reused in assignment feedback.

Moodle file identity also depends on contextid, itemid, filepath and filename. The same area can hold files from different users or instances.

Read-only SQL

The examples use the mdl_ database prefix. Replace it with your installation's actual prefix. Never run DELETE, TRUNCATE or direct mutations against mdl_files. Directory placeholders with filename = '.' are excluded from file counts.

Totals by area

SELECT f.component, f.filearea,
       COUNT(*) AS registros,
       COALESCE(SUM(f.filesize), 0) AS bytes_logicos
  FROM mdl_files f
 WHERE f.component = 'assignfeedback_editpdf' AND f.filearea = 'stamps' AND f.filename <> '.'
 GROUP BY f.component, f.filearea
 ORDER BY bytes_logicos DESC;

Largest files to investigate

SELECT f.id, f.contextid, f.itemid, f.filepath, f.filename,
       f.filesize, f.contenthash, f.timemodified
  FROM mdl_files f
 WHERE f.component = 'assignfeedback_editpdf' AND f.filearea = 'stamps' AND f.filename <> '.'
 ORDER BY f.filesize DESC
 LIMIT 25;

Outside a report inventory

Replace report ID 5 with your File X-Ray report ID. This identifies files missing from course backup selections, not files proven unused.

SELECT f.component, f.filearea,
       COUNT(*) AS fora_do_inventario,
       COALESCE(SUM(f.filesize), 0) AS bytes_fora
  FROM mdl_files f
 WHERE f.component = 'assignfeedback_editpdf' AND f.filearea = 'stamps' AND f.filename <> '.'
   AND NOT EXISTS (
       SELECT 1
         FROM mdl_local_filexray_file fx
        WHERE fx.reportid = 5 AND fx.fileid = f.id
   )
 GROUP BY f.component, f.filearea
 ORDER BY bytes_fora DESC;

Checks before cleanup

Review PDF annotation settings before removing stamp images. They are not student attachments and may be outside course backups.
