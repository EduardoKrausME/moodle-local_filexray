File analysis without guesswork

The inventory finds references.
Interpretation needs context.

Moodle stores files across courses, users, components and file areas. File X-Ray begins with the references selected by a standard course backup and makes clear which conclusions this comparison cannot support.

⌁

Safer investigations

Separate records found in the inventory from those not found, without automatically labelling them orphaned.

Native backup without an MBZ

Use Moodle's logic.
Don't copy files.

The inventory performs native per-course backup discovery steps and stops before physical file copying and the final archive creation.

The selected IDs come from Moodle's own backup annotations, rather than guessing file ownership from database contexts alone.

Long-running processing

69 courses.
One continuous process.

File X-Ray stores a course row for each report and runs sequential ad-hoc tasks through Moodle cron. Processing continues even after the browser tab is closed.

The page polls status over AJAX, displays counts and supports retrying failed courses. Once finished, it opens the comparison automatically.

Beyond course files

Drafts, backups, icons
and other areas.

The report groups files by component and filearea, including user drafts, profile images, backup files, badges and H5P content.

Counts and byte totals are logical measures of records, not necessarily distinct physical disk bytes. More than one file entry may share a contenthash.

No automatic deletion

Outside an inventory does not mean
physically orphaned.

Other Moodle plugins may store files outside standard course backup selection. File X-Ray does not check every possible dependency, scan the physical moodledata/filedir directory or compute safely reclaimable bytes.

✓

Read-only files

File X-Ray does not delete Moodle file records or physical data.

♙

Native permissions

local/filexray:view and local/filexray:run govern access and administration.

▤

Managed history

Reports can be deleted and retention limits can be configured.

◎

Visible failures

Comparisons with failed courses are marked as provisional.

Get started

Install in Moodle.
Keep cron running.

Available as a local plugin for Moodle 4.5 or later. Place it in local/filexray, perform the standard Moodle upgrade and visit Site administration → Reports → File X-Ray.
