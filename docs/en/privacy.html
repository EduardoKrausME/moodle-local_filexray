Privacy Policy

Understand which file metadata File X-Ray stores inside Moodle and which responsibilities remain with the institution.

Last updated · 14 October 2026

This document explains the general plugin and public documentation behaviour. It does not replace the privacy policy of the institution operating Moodle.

1. Data controller

File X-Ray is an open-source plugin installed on an institution's Moodle infrastructure. The institution determines permissions, retention periods and responses to privacy requests under applicable laws. Publishing source code on GitHub does not automatically transfer Moodle data to the maintainer.

2. Stored data

Each report stores the Moodle ID of its creator, inventoried course IDs, display names, job statuses, timestamps, error messages and file metadata such as internal IDs, content hashes, components, file areas, context IDs, names and logical byte sizes. These are records already present in the Moodle instance.

3. Purpose

These records support administrative diagnostics, per-course backup file reference inventories, progress monitoring and comparison with Moodle's current logical file records.

4. Storage and sharing

Inventories are generated within the institution's Moodle infrastructure and stored in the plugin's local database tables. File X-Ray does not require an external service to produce reports. The Moodle operator's hosting, backups, server logs and optional integrations may have separate policies.

5. Access and security

Moodle capability local/filexray:view governs read access. Capability local/filexray:run controls creating, resuming and deleting reports. Grant these permissions only to appropriate administrative roles.

6. Retention and deletion

Administrators can configure the maximum number of reports to keep and delete specific reports. Deleting a report removes only its inventory data and does not alter original files stored by Moodle.

7. Rights and contact

Requests about data stored by a particular Moodle instance should be addressed to the institution operating it. For questions about the open-source project, use the public repository contact channels.

8. Documentation website

This static website offers an optional theme preference stored locally in the browser and a language selector that uses browser language preferences. The website does not analyse Moodle or collect report contents from institutional installations.
