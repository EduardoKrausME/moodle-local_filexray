Arquivos dos temas

Componentes de nome theme_... pertencem a temas instalados. As áreas como logo, loginlogo e background_profile_image dependem de cada implementação e representam frequentemente recursos de identidade visual.

O que são esses arquivos

theme_* / * — Componentes de nome theme_... pertencem a temas instalados. As áreas como logo, loginlogo e background_profile_image dependem de cada implementação e representam frequentemente recursos de identidade visual.

A identidade de um arquivo no Moodle também depende de contextid, itemid, filepath e filename. A mesma área pode conter arquivos de usuários ou instâncias diferentes.

SQL de somente leitura

Os exemplos usam o prefixo mdl_. Troque-o pelo prefixo real da sua instalação. Não execute DELETE, TRUNCATE ou modificações diretas em mdl_files. Diretórios com filename = '.' não entram na contagem de arquivos.

Consulta de totais

SELECT f.component, f.filearea,
       COUNT(*) AS registros,
       COALESCE(SUM(f.filesize), 0) AS bytes_logicos
  FROM mdl_files f
 WHERE SUBSTRING(f.component, 1, 6) = 'theme_' AND f.filename <> '.'
 GROUP BY f.component, f.filearea
 ORDER BY bytes_logicos DESC;

Arquivos maiores para investigação

SELECT f.id, f.contextid, f.itemid, f.filepath, f.filename,
       f.filesize, f.contenthash, f.timemodified
  FROM mdl_files f
 WHERE SUBSTRING(f.component, 1, 6) = 'theme_' AND f.filename <> '.'
 ORDER BY f.filesize DESC
 LIMIT 25;

Fora do inventário de um relatório

Substitua o número 5 pelo ID do relatório do File X-Ray. O resultado mostra ausência da seleção dos backups dos cursos, não ausência de uso.

SELECT f.component, f.filearea,
       COUNT(*) AS fora_do_inventario,
       COALESCE(SUM(f.filesize), 0) AS bytes_fora
  FROM mdl_files f
 WHERE SUBSTRING(f.component, 1, 6) = 'theme_' AND f.filename <> '.'
   AND NOT EXISTS (
       SELECT 1
         FROM mdl_local_filexray_file fx
        WHERE fx.reportid = 5 AND fx.fileid = f.id
   )
 GROUP BY f.component, f.filearea
 ORDER BY bytes_fora DESC;

O que verificar antes de qualquer limpeza

Confira se o tema está instalado, em uso ou ainda possui configurações associadas. Apagar manualmente arquivos pode causar imagens ausentes no login ou no perfil.
