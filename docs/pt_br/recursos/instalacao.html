Instalação e primeiros passos

Instale o File X-Ray como plugin local do Moodle, verifique as permissões e deixe o cron executar o inventário em segundo plano.

Requisitos

O plugin foi desenvolvido para Moodle 4.5 ou superior e requer acesso administrativo para instalação. O PHP e o banco de dados devem ser compatíveis com a versão do Moodle utilizada. O cron precisa estar ativo para executar as tarefas ad-hoc de inventário.

Instalação

Coloque os arquivos do plugin na pasta local/filexray do Moodle, execute o processo padrão de atualização e acesse Administração do site → Relatórios → File X-Ray. O plugin é configurado por capacidades no contexto do sistema.

Atualização via CLI

php admin/cli/upgrade.php --non-interactive
php admin/cli/purge_caches.php
php admin/cli/cron.php

O último comando executa uma passagem do cron. Para um site em produção, mantenha o agendamento contínuo já utilizado pela instituição.

Criando o primeiro relatório

Abra a página principal do File X-Ray e selecione Gerar relatório. A ferramenta registra a lista de cursos do momento e agenda a primeira tarefa. Use a tela de andamento para acompanhar cada curso e, ao concluir, o próprio plugin abre a comparação. Também é possível criar um relatório pela CLI com php local/filexray/cli/create_report.php.

Retenção e limpeza

A configuração de retenção estabelece um limite para a quantidade de relatórios guardados. Quando o limite é atingido, o plugin remove o relatório mais antigo antes de criar um novo. Excluir um relatório remove apenas seus dados de inventário, não arquivos originais do Moodle.

O File X-Ray não instala um serviço externo, não executa o backup completo e não gera MBZ. A análise pode consumir tempo de CPU e banco de dados e deve ser planejada conforme o tamanho da instalação.
