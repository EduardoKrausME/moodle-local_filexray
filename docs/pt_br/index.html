O inventário revela referências.
A análise exige contexto.

O Moodle distribui seus arquivos entre cursos, usuários, componentes e áreas de armazenamento. O File X-Ray começa pelas referências que um backup normal de curso encontra e deixa explícito aquilo que não é possível concluir só com essa comparação.

◎

Arquivos referenciados

Registra os IDs e metadados que o backup nativo seleciona, associados ao curso e ao relatório.

▤

Relatórios persistentes

Mantém o estado de cada curso, seus totais, horários e falhas mesmo depois que o navegador é fechado.

⌁

Investigação segura

Separa o que foi inventariado do que não foi encontrado, sem chamar automaticamente esses registros de órfãos.

O inventário executa as etapas de descoberta do backup de cada curso e para antes da fase que copia os conteúdos físicos e monta o arquivo final.

O plugin usa as referências finais do próprio backup. Isso reduz as suposições sobre quais componentes e áreas são utilizados pelo curso.

Ao criar um relatório, o File X-Ray registra uma linha por curso e aciona tarefas ad-hoc em sequência. O cron continua trabalhando mesmo que a página seja fechada.

A interface consulta o estado por AJAX, atualiza os totais e permite retomar cursos com falhas. Ao terminar, o relatório leva diretamente à comparação.

Arquivos fora do contexto dos cursos

Drafts, backups, ícones
e outras áreas.

O relatório também organiza arquivos por componente e filearea, incluindo rascunhos do usuário, imagens de perfil, backups, distintivos e arquivos H5P.

As quantidades representam tamanhos lógicos dos registros, não necessariamente bytes únicos em disco, pois diferentes registros podem compartilhar o mesmo contenthash.

Sem apagamento automático

Um registro ausente não prova
que o arquivo é órfão.

Um plugin pode manter arquivos fora do conjunto que o backup de cursos seleciona. A comparação não valida todos os vínculos possíveis, não percorre fisicamente moodledata/filedir e não calcula espaço seguramente recuperável.

✓

Somente leitura dos arquivos

O File X-Ray não remove entradas de mdl_files nem arquivos físicos.

♙

Permissões nativas

As capacidades local/filexray:view e local/filexray:run controlam consulta e administração.

▤

Histórico sob controle

Relatórios armazenados podem ser removidos e têm limite de retenção configurável.

◎

Falhas identificadas

Uma comparação com cursos que falharam é sinalizada como provisória.

Disponível como plugin local para Moodle 4.5 ou superior. Instale o código em local/filexray, execute a atualização padrão do Moodle e abra o painel em Administração do site → Relatórios → File X-Ray.
